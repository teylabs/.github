# Security Policy

## Supported Versions

Security fixes are released for the latest major version of each Tey Labs package. For packages before 1.0, that is the latest 0.x minor version. A package may list additional supported versions in its own README.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately instead, either:

- through GitHub's private vulnerability reporting, using **Report a vulnerability** on the affected repository's **Security** tab, or
- by email to [jasper@teylabs.com](mailto:jasper@teylabs.com).

Please include a description of the issue, the steps to reproduce it, the affected versions and, if you can, a suggested fix. You will receive a reply as soon as possible, and you will be kept informed while a fix is prepared and released.
