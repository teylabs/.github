# Tey Labs

Open-source Laravel packages by [Jasper Tey](https://github.com/jaspertey), built in public.

| Package | What it does |
| --- | --- |
| [tey/laravel-ddd](https://github.com/teylabs/laravel-ddd) | Domain Driven Design toolkit for Laravel: `ddd:*` generators, custom layers and domain auto-discovery |
| [tey/mod](https://github.com/teylabs/mod) | Layout-aware generators and discovery for Laravel: feature folders, modules or your own layout, with `make:*` and auto-discovery still working |

Questions and ideas go to each package's Discussions. See our [package conventions](https://github.com/teylabs/.github/blob/main/CONVENTIONS.md) for how we build and release.
